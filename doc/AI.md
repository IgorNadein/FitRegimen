# AI workflow: prompt preparation and validated plan import

FitRegimen prepares requests and imports generated plans. It does not run a language
model or send requests to an AI provider. The same JSON files can be written by a
person, shared by another user, or generated by an external assistant.

1. Open **Programs → + → AI prompt**, or **Food → + → AI nutrition plan**.
2. Enter the goal and constraints. Review whether profile data is included.
3. Generate and inspect the prompt, then copy/share it to your chosen assistant.
4. Save the response as a raw `.json` file, without Markdown code fences or prose.
5. Training: return to **Programs → + → Import program**. Nutrition: use
   **Import finished JSON** on the AI screen, or **Import plan** in Food.
6. Read any import error, correct the file if necessary, and inspect/edit the
   imported days, exercises or meals before using the plan.

No external AI account is needed to try the import flow: use
[program.json](demo/program.json) and [nutrition.json](demo/nutrition.json).
These are hand-authored examples of the interchange formats, not claims of AI output.

## Checks actually implemented

| Boundary | Current behavior |
| --- | --- |
| Training JSON | Parse a single JSON value; accept program format versions 1–3; check file type, nonblank program name and nonempty days. Normalize legacy v1 tasks. |
| Training persistence | Resolve exercise references; reject missing exercise names or unresolved references; insert the program transactionally. Some enum spellings, defaults and nonnegative timing fields are normalized for compatibility. This is not strict validation of every training quantity. |
| Nutrition JSON | Require explicit type/version; support nutrition format v1; limit input to 8 MiB; reject trailing JSON and unknown fields. |
| Nutrition structure | Validate day/meal/item counts, names and text lengths, meal times, finite nonnegative numeric values with upper bounds; reject private profile/scheduling/backup fields in standalone files. |
| Nutrition persistence | Validate again and insert transactionally. The AI screen can attach selected local profiles/training context when it still matches the generated prompt. |
| Privacy | Selected profile data goes into the prompt only through the profile controls. An external service receives whatever the user copies/shares to it. Standalone nutrition export excludes private backup links. |

Validation establishes compatibility and data integrity. It does not establish
exercise suitability, factual accuracy of food estimates, or personalized safety.
After import, the ordinary editors expose the plan for human review; there is no
separate AI approval or preview engine.
