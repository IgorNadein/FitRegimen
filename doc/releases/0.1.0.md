# FitRegimen 0.1.0

First downloadable portfolio release: build a training program, complete a guided
workout, plan meals, and restore your data from a portable backup.

FitRegimen is a GPLv3-or-later fork of **FitoTrack by Jannis Scheibe and contributors**.
The GPS/indoor tracker, route maps and original statistics come from upstream.
This fork adds the program/session and nutrition workflows.

## Download and install

Requires **Android 8.0+**. Download **FitRegimen-0.1.0.apk** from the assets below,
open it on your phone, allow APK installation for your browser/file manager if
Android asks, and tap **Install**. No account or API key is required.

The APK is a signed, optimized release build (`com.fitregimen.app`, versionCode
1621). It installs separately from FitoTrack and the CI debug app. See the
[installation guide](https://github.com/IgorNadein/FitRegimen/blob/v0.1.0/doc/INSTALL.md)
for updates, ADB installation, checksum verification and the certificate fingerprint.

**Установка:** скачайте **FitRegimen-0.1.0.apk**, откройте на Android 8.0+, разрешите
установку для использованного браузера/файлового менеджера и нажмите «Установить».
Аккаунт и API-ключ не нужны.

## Five-minute demo

1. Download `program.json`; use **Programs → + → Import program**.
2. Open **Portfolio demo**, tap **Start program → Start workout → Start workout**.
3. Confirm two manual sets and wait for the 20-second timer; the result is **3 / 3**.
4. Import `nutrition.json` through **Food → + → Import plan** or the AI screen's
   **Import finished JSON** control.
5. Use **Settings → Database** to export and restore a backup. The attached
   `portfolio-backup.ftb` is a ZIP-format backup exported from the completed demo.
   **Replace** replaces local data; **Merge** combines it with existing data.

The examples contain fictional data. No physical exercise, GPS, account or external
AI is needed to inspect the interface. The included backup contains the demonstration
session dated September 9, 2026, not today's workout.

## AI scope

**Prompt preparation and validated import of externally generated plans.** The app
builds the request and checks the imported JSON; generation happens in an external
assistant chosen by the user. Validation checks data compatibility, not personal
suitability of training or nutrition recommendations.

## Backup correction

Full-backup export now uses Kotlin property names consistently with import. Older
backups containing `active` / `rest` flags are also accepted, preserving the active
profile and rest days. This fixes an own-backup restore failure found during the demo.
