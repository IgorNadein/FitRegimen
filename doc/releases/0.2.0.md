# FitRegimen 0.2.0 — in-app updates

Version code: 1622

**Settings → Updates** now checks GitHub Releases, downloads the latest signed APK
with progress and cancellation, and opens the Android installer. The flow follows
Palenok and 12609. The screen is available in English, Russian, German and Spanish.

**Настройки → Обновления:** проверка новой версии, скачивание APK с прогрессом и
отменой, затем установка через системное окно Android.

## Install this release

Download **FitRegimen-0.2.0.apk** below and open it on **Android 8.0+**. Allow APK
installation for your browser/file manager if Android asks, then confirm installation.
No account or API key is needed.

**If you have 0.1.0, install this APK manually once, over the existing app. Do not
uninstall it.** This adds the updater and preserves your local data. Subsequent
releases can be obtained from **Settings → Updates → Download update → Install update**.
If Android asks, allow installation from FitRegimen, return and press Install update again.

**Если у вас 0.1.0, один раз установите этот APK вручную поверх приложения, без
удаления.** Данные сохранятся. После этого новые релизы можно получать через
**Настройки → Обновления → Скачать обновление → Установить обновление**.
При запросе разрешите установку из FitRegimen, вернитесь в приложение и снова нажмите
«Установить обновление». Последний шаг подтверждается в установщике Android.

## Verification before installation

The updater validates release metadata and HTTPS destinations, download size and
SHA-256, APK package and numeric version, and the signing certificate against the
installed application. Incomplete, modified, mismatched or differently signed APKs
are rejected. Cached files are checked again before installation.

Checks run when opening the Updates screen or pressing Check again. Downloads and
installation are explicit; no background checks or automatic installation were added.
No profile, nutrition, workout or backup data is included in GitHub update requests.
Debug builds use a separate package and cannot install release updates from this screen.

The signed package is **com.fitregimen.app**, with the same release certificate as 0.1.0.

## Try the app

The included `program.json`, `nutrition.json` and `portfolio-backup.ftb` are synthetic
examples for the [five-minute demo](https://github.com/IgorNadein/FitRegimen/blob/v0.2.0/doc/demo/README.md)
([на русском](https://github.com/IgorNadein/FitRegimen/blob/v0.2.0/doc/demo/README.ru.md)).
The backup includes a demonstration session dated September 9, 2026. **Replace**
restores it by replacing local data; **Merge** combines it with existing records.

AI scope remains **prompt preparation and validated import of externally generated
plans**. Generation happens in an external assistant chosen by the user.
